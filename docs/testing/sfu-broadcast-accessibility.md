# SFU broadcast accessibility evidence

The Playwright specification exercises the productive broadcast control only
when the real browser stack is explicitly enabled. A skipped local test is not
release evidence. The Python adapter requires separate real Chromium and
Firefox processes, real media, complete lifecycle instrumentation, Axe results,
responsive assertions and cleanup for stop, navigation, logout, room change
and revoke.

Viewport emulation is not accepted as another browser or device. Screenreader
compatibility remains unclaimed unless a real NVDA or VoiceOver automation
result is verified. Axe exceptions use the same owner, expiry, compensating
control and approval contract as supply-chain exceptions.
