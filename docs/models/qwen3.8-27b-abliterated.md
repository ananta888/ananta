# Qwen3.8-27B abliterated research profile

The profile is an isolated research-only comparison against the unmodified
Qwen3.8-27B. It is disabled and unroutable by default. The first candidate is
UD-IQ3_XXS through a pinned local llama.cpp-compatible endpoint; vision,
streaming, JSON, reasoning parser and tools remain unknown or disabled until
exact observations exist.

Do not use it for participants, public chat, customer communication, personal
data, regulated decisions or production agents. Prefer the official base for
ordinary use. A new digest, ablation line, runtime major version or policy
requires a complete new evaluation.
