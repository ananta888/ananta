# ADR: Qwen3.8-27B abliterated research profile

Status: isolated-research-only / runtime evidence pending (2026-09-04)

The derivative is integrated only as a disabled `unsafe_research` profile.
The Hub owns provenance, expiring authorization, routing denial, evidence and
audit; workers run closed assignments. This preserves the hub-worker boundary
and keeps policy separate from provider execution.

Production and normal fallback are permanently excluded. Local execution also
remains blocked until a pinned runtime, imported exact artifact and Hub-bound
hardware, quality and red-team results exist. The official base remains the
normal reference.
