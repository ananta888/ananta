## Migration decisions

- `chat_use_rag`, `chat_rag_profile`, and `rag_top_k` are non-canonical legacy aliases. They are quarantined in `legacy_settings` / `legacy_settings_delta`; the canonical keys are `chat_architecture_analysis_mode`, `chat_retrieval_profile`, and `chat_rag_top_k`.
- Unknown legacy values are preserved in quarantine and never silently discarded.
- Materialized session `settings` remain a compatibility projection; only profile `settings` and session `settings_delta` are persisted as authored deltas.
